# Privacy

This repository contains instructions (Agent Skills) and configuration files only. It collects, stores and transmits nothing by itself.

When your assistant uses these skills, it connects to the hosted Apify MCP server (`mcp.apify.com`) or the Apify API with **your own** Apify account, and runs publicrecords Actors there. Your inputs, the run results and your account data are then handled by Apify under the [Apify Privacy Policy](https://apify.com/privacy-policy). The Actors read public sources only (government portals, public job boards, public web pages) and are built for organizations, not people.

Questions: open an issue at https://github.com/GeminiGeorge22/publicrecords-skills/issues.
